## ПР2. Ответы на контрольные вопросы

1. Потому что double считает с маленькой ошибкой, например 0.1 + 0.2 получается не ровно 0.3, а 0.30000000000000004. Для денег так нельзя, а decimal считает ровно.

2. Число начинает считаться заново с минимума. Например у byte если к 255 прибавить 1 то будет 0.

3. В Python переменная может менять тип как хочет, а в C# через var тип просто не пишешь сам, его определяет компилятор при компиляции и потом он уже не меняется.

4. Всегда string, даже если ввели число.

5. int.Parse если ввести буквы выдаёт ошибку и программа вылетает, а int.TryParse не вылетает а просто возвращает false.

6. false значит что не получилось перевести строку в число, а в переменную out запишется 0.

7. Когда пользователь сам вводит число, например возраст, он может ошибиться и написать буквы. С TryParse программа не упадёт.
